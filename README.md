<h2>🧩 Design meets development</h2>

<p>
  I'm a UX/UI designer and an active frontend developer. I work across both
  disciplines — from understanding user needs and shaping interface concepts
  to implementing responsive interfaces with React and TypeScript.
</p>

<p>
  At <strong>Kazan Federal University</strong>, I worked on redesigning a
  university web portal, improving navigation and user flows and creating
  80+ adaptive screens, from wireframes to interactive prototypes.
  I also worked within an existing design system.
</p>

<p>
  My frontend journey includes over a year at <strong>PetPortal</strong>,
  where I worked with React and TypeScript alongside a UX/UI designer.
  I continue to develop my frontend skills while growing as a designer.
  Understanding both sides helps me make design decisions with implementation
  in mind — without losing sight of the user experience.
</p>
